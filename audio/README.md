# ملفات صوت المذيع

إعلان كل رحلة = ملف الوجهة والناقل + ملف الوقت، فالرحلة نفسها تأخذ الوقت الصحيح لكل يوم.
بعد رفع ملف جديد، أضف اسمه (بدون .mp3) إلى `CLIPS` في index.html.

- `welcome` — أهلاً بكم في مطار الجوف.
- `next` — الرحلة القادمة (تُقال بعد الافتتاحية ثم سكتة ثانية).
- الوجهة والناقل: CAI-SM, JED-SV, SHJ-G9, RUH-F3, ELQ-SV, RUH-XY, CAI-NP, HMB-SM
- الأوقات: t0900, t0945, t1015, t1655, t1800, t1840, t1915, t2045, t2200, t2230
- قادمة لاحقاً: RUH-SV (السعودية للرياض) وأوقاتها t0835, t1055, t1700, t2345
